# Web Scraping Project with Python 🕸️

This project is part of my Python course assignments. In this project, I have used Web Scraping techniques to extract data from a web page using `requests` and `BeautifulSoup` libraries.

---

## Project Description

In this project, I collected information such as:

- The title of the web page  
- Data from a specific HTML class (e.g., book titles or product names)  
- Image links from the web page  

I used any website of my choice (such as an online library or bookstore) for scraping the data.

---

## Project Goals

The main goal is to extract the following information from a target website:

1. Web page title  
2. Content from a specific HTML class (e.g., book titles or product names)  
3. Image links of books or products  

---

## Tools & Libraries Used

- Python 3.x  
- requests  
- BeautifulSoup4
